# Alumni IUT Laval Theme

Thème pour le site web du réseau Alumni IUT Laval.

## Description

Ce thème contient les composants HTML/CSS pour le site web de la communauté des anciens étudiants de l'IUT de Laval.

## Structure

- `/assets` - Fichiers CSS, JS et images
- `/components` - Composants HTML réutilisables
- `/pages` - Pages HTML complètes
